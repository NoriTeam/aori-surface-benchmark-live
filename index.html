Architecture audit — measured / unavailable / not applicable
Roughness · scalar only

Reference has no roughness texture or multi-sample roughness loop. Ablation tests its edge coefficient, not imaginary samples.

Transmission · scalar alpha/tint

No refraction pass; background diffusion is CSS backdrop-filter.

Geometry / edge · SDF fragment shader

Reference evaluates the distance field three times for finite-difference normals; derivative-normal tests one evaluation.

Passes · one material pass per visible stage

No separate light/roughness/blur WebGL passes to merge in reference. Hybrid introduces an FBO material pass and a native-coverage/edge recomposition pass. Pass counters count render-target sweeps; draw calls count stage draws.

Textures / framebuffers · none in reference

Hybrid owns one reusable RGBA8 texture/FBO. Report attachment bytes only, not total GPU memory.

Masks / clipping · SDF coverage + CSS overflow

Clipping toggle measures browser overflow clipping. No SVG masks or SVG filters exist: not applicable.

Antialiasing · shader fwidth AA

WebGL MSAA disabled. AA ablation is diagnostic only and never chosen by AUTO.

Compositing · browser-owned

Whole-frame paired deltas only. CSS blur, raster, text and compositor GPU time are unavailable through WebGL timers.

Scheduling / React · one benchmark RAF

One clock drives fixtures and renderer. No React commits inside measured frames. Reference adapter differs from v1 scheduler; compare v2 pairs, not v1 absolute FPS.

Caching / instancing · bounded candidates

Cached stage uniforms/static stages and clipped fill are tested. Reference already batches up to 12 bodies per draw; no per-body geometry meshes to instance.

Methodology / visual fidelity / headroom limits

BASE + feature and FULL − feature are adjacent matched pairs. Each fixed trial: 1s warm-up + 4–5s measured. AUTO alone adapts; 2 deficient windows, 8s cooldown, 5 strong windows and 15s for upgrades. Frozen A/B uses shared geometry/state; raw framebuffer diff excludes browser blur/text. Performance gain never proves visual equivalence.

Resolution 1.00 means actual device DPR, not the old 1.25 cap. All DOM/text stay native. Reference, optimized and 25s sustained tests are separate. Reported Mali/S25/iPhone observations from previous user runs are not substituted for new measurements.

Methodology and limits

Each active stage: 1s warm-up + 5s measured; sustained: 1s + 25s. Idle: 2s settling + 4s measured. Every stage starts from the same deterministic layout. 16/32 bodies use 2/4 scissored scenes of eight bodies, retaining the real renderer’s limit. CPU, WebGL GPU and frame intervals are never summed.

Missed slots = max(0, round(interval / calibrated budget) − 1); missed % = missed slots / all observed slots. Jank = interval > 1.5× budget; long frame = interval > max(50ms, 2× budget).

EXCELLENT: p95 ≤1.08× budget, p99 ≤1.5×, missed <0.5%, CPU p95 <0.5×. PASS: p95 ≤1.2×, missed <2%. MARGINAL: p95 ≤2×, missed <10%. Otherwise FAIL. Unstable calibration is UNAVAILABLE. Quality overall excludes scaling stress; raw failed stages are retained. GPU N/A does not become a made-up estimate.

Blur delta compares identical moving backdrops with blur on/off. Browser APIs cannot isolate absolute CSS-compositor GPU time; a refresh ceiling may hide its cost. A static fallback probe cannot demonstrate animated UI suitability. Results from mobile viewport on a desktop are not real-phone results.
